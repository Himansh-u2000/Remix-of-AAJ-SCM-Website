---
name: Content fidelity
description: Never edit user-provided copy (titles, descriptions, headings, body) without asking first
type: preference
---
When the user provides text/content (page copy, meta titles, descriptions, headings, body content from documents), use it VERBATIM. Do not shorten for SEO limits, fix typos, rephrase, or "improve" wording. If something seems problematic (e.g. title >60 chars, possible typo), flag it and ASK before changing. **Why:** User explicitly instructed this after meta titles were trimmed without consent.
